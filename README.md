# Cuiz

Desktop app for interviews. This repository only publishes installers. Download the latest build from [Releases](https://github.com/richaxe/cuiz/releases).

## Windows

| File | Use |
| --- | --- |
| `Cuiz Setup <version>.exe` | Installer for 64-bit Windows |
| `Cuiz Setup <version>-ia32.exe` | Installer for 32-bit Windows |
| `Cuiz <version>.exe` | Portable 64-bit app, no install |

Windows SmartScreen may warn that the app is unrecognized. Choose **More info**, then **Run anyway**.

## macOS

| File | Use |
| --- | --- |
| `Cuiz-<version>-arm64.dmg` | Installer for Apple silicon |
| `Cuiz-<version>.dmg` | Installer for Intel Macs |
| `Cuiz-<version>-arm64-mac.zip` | Portable app for Apple silicon |
| `Cuiz-<version>-mac.zip` | Portable app for Intel Macs |

Open the disk image and drag Cuiz to Applications, or unzip the portable archive and open `Cuiz.app`.

macOS may block the app because it is not notarized. Right-click the app, choose **Open**, then choose **Open** again.

## Updates

Each release is attached to a version tag such as `v1.0.0`. The newest files are always on the [latest release](https://github.com/richaxe/cuiz/releases/latest).
